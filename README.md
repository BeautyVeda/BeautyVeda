# BeautyVeda Pro — GitHub Pages Starter

## Included
- Responsive premium homepage
- Blog post template
- Category pages
- Search page
- About, Contact and Privacy pages
- SVG logo
- SEO meta tags + canonical placeholder
- `robots.txt` + `sitemap.xml`
- Mobile navigation
- Newsletter/contact demo interactions

## GitHub Pages
1. Create a public repository, e.g. `beautyveda`.
2. Upload all files to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Replace `YOUR-USERNAME` in `index.html`, `robots.txt` and `sitemap.xml` with your GitHub username.
5. Open the Pages URL shown by GitHub.

## Before publishing
Replace demo articles with original, useful content. Update the canonical URL and sitemap URL. Replace the contact/privacy templates with your real details and policies. Connect the newsletter/contact forms to a real form/email service if needed.

## Important
This is a static GitHub Pages site. It is not a full CMS like WordPress. For dozens/hundreds of posts, you can create additional HTML post pages or later migrate to a CMS/static-site generator.
